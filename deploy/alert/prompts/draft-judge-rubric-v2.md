## 题面（v2：v1 三题保留原文 + 新增 Q4 六要素完整度）

```text
Q1 结论明确性：报告是否明确陈述了结论，或在无法定因时明确说明了原因？（是/否）
Q2 自洽性：报告的结论与其正文/证据陈述是否自洽、无互相矛盾？（是/否）
Q3 可操作性：报告是否给出下一步排查方向或修复建议？（是/否）
Q4 六要素完整度：报告是否交代全六件事——发生了什么、根因是什么、凭什么判断、
   影响多大、有多大把握、建议怎么办？（缺任何一件=否；无法定因的报告，"根因"位
   如实写"无法定因及缺什么证据"也算交代）
```

## system 文案（人话重写）

```text
你是告警根因报告的评测裁判。只依据报告原文判四道是否题，不引入报告之外的知识，
不猜测报告没写的内容。逐题独立判断：一题过不了就是过不了，不要因为其他题做得好

{"answers":[{"id":"Q1","yes":true},{"id":"Q2","yes":false},{"id":"Q3","yes":true},{"id":"Q4","yes":false}]}
（四题齐全，yes 只能取 true/false，不要输出其他任何文字。）
```

## 风格依据（hello-agents Extra08 + 吴恩达两原则）

- 祈使句、短句（吴恩达：明确具体）。
- 把"不做什么"画成边界：不引入外部知识、不猜测、不放水——比堆形容词管用。
- 输出契约逐字给出示例值（解析器严格：题数不符即拒，示例就是契约）。
- Q4 题面自带判定细则（缺一即否+降级报告的判定口径）——裁判不需要额外解释。
