#### DP-02 故障卡（FAIL → TB-03）

1. **现象**：期望 PASS=77 FAIL=0；实际 DP-02 第 4 条断言 FAIL——注入
   `GITHUB_WRITE_TOKEN=dp02-fake-token` 的一次性容器 dp02-control 检出失败日志后，

   ```bash
   docker inspect dp02-tb03 -f '{{.State.Status}} {{.RestartCount}}'   # 检出瞬间

   ```
