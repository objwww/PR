## G0-07 Task 状态机接线 + episode 乱序修复（BA-11①、BA-12①）

- `RcaWorker`/`RcaRunOrchestrator` 的 task 状态推进经 `RcaTaskStateMachine`
- **episode 乱序修复**（`IncidentProjector.java:176-196`）：incident 已是 RESOLVED 时收到 firing，先比较 `startsAt` 与 `resolvedAt`——**startsAt 早于 resolvedAt 的只追加 alert_event + 计数，不复活 incident、不铸 run**；startsAt 晚于 resolvedAt 的才走 generation+1 新 episode
- 验收：新增 L3 用例"同 episode 内 resolved 先于 firing 到达 → incident 保持 RESOLVED、零新 run"；状态机接线验收同 G0-05
