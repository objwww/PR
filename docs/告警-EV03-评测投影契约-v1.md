## 2. null 语义纪律（§5.2）

- 新比率一律 `RatioStat{numerator, denominator, status}` 三件套：
  分母 0 → NOT_APPLICABLE（原始计数照报，如 0/0）；分子分母未回填（RUNNING/FAILED）
  → UNKNOWN 且两值 null。不填 0 冒充未知。
- 四率沿 ScenarioMetrics 原公式：coverage=decidable/total、
  conditionalAccuracy=hits/decidable、endToEndHitRate=hits/total、
  unresolvedRate=unresolved/total；错误确认 falseConfirmation=(decidable−hits)/decidable，
  与症状 FP 分开命名。
- 旧数值字段（coverage/conditionalAccuracy/endToEndHitRate/unresolvedRate/tp/fp/fn）
  原样保留——存量序列化契约不静默改（ScenarioMetrics 零分母输出 0.0 同理不动）。
- 列表与详情同口径；asOf 快照直读主表，过滤后分母由后端聚合提供，不把当前加载页当全量分母。

## 3. RV08 红线（用量/费用不猜归属）

model_call_ledger.review_run_id 外键指向 PR 域 review_run（V5），与 eval_run/rca_run
无关。本期用量分面 usageStatus/costStatus 恒 UNKNOWN、不投影任何数字：
**等 R7 RCA 调用账本与 eval→RCA 显式身份链接线（EV-06）后才有真实数据源**。
代码面保证：PostgresEvalQueryReader 全部 SQL 不出现 model_call_ledger，
不按时间窗、不按同 UUID 猜测归属（EU17 验收归 EV-06）。
