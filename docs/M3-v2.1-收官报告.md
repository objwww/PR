### 2. TB-28 复验（DP-21 lease 负例日志点名）—— 已关闭

**原故障**：DP-21 lease 负例拒启正确，但日志点名断言 FAIL（触发 per-call>deadline 校验，未到达 lease 不等式校验）

**根因**：
- compose 环境块硬编码 `APP_MODEL_PERCALLTIMEOUTMS=120000`
- 负例注入 `APP_MODEL_GATEWAY_TOTALDEADLINEMS=55000`
- 未注入 percall 参数 → 120000>55000 触发 per-call 校验先炸，lease 不等式校验未及触达

**修复**（INC-66）：
- smoke-test.sh DP-21 负例补第三键 `-e APP_MODEL_PERCALLTIMEOUTMS=20000`
- 合法三元组（20000 ≤ 55000）使校验链走到 lease 不等式（60 ≤ 55+10 拒）→ 日志点名串命中

**复验结果**（第二轮阶段 B）：
- DP-21 **2/0 全绿**
- 拒启 exited/1 + 日志含 "app.worker.max-lease-seconds 必须大于 app.model.gateway.total-deadline-ms"

**状态**：TB-28 **已关闭**
