## 7. E2E 环境经验（工具面，非缺陷）

- **switchboard 2s 可丢缓存**：激活后必须等快照过期（驱动 sleep 3s）再注入，否则 F1 旁路/F3 UNKNOWN 读旧空快照不触发。
- **promtool time() 是相对评估时刻**非墙钟：staleness 用例样本值用 0 而非 epoch。
- **Ubuntu 26.04 bash 5.3 禁用 /dev/tcp**：compose 健康检查改 wget。
- **场景名全局唯一（uq_chaos_scenario）**：重跑必须换名——编排器以 run tag 统一派生全部 scenario/target/intent 名。
- **编排器判定必须吃退出码**：只 grep FAIL 行会漏 Traceback 假绿（attempt 6 教训）；已改退出码落盘 + Traceback 双查（BA-18 同族教训）。
