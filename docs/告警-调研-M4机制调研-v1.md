## §0 总结论：四条线各自的"可借鉴组合"

- **工具层（M4-13~18）**：以 MCP Tool 契约（name/description/inputSchema/annotations）+ spring-ai ToolDefinition/ToolCallback 为底座，自加 version/risk/timeout/resultLimit/schemaHash 五个加固字段（差异化，无开源先例但正当）；注册期 fail-fast（smolagents 校验+HolmesGPT prerequisites+三家重名静默覆盖反面教材）；权限=prometheus-mcp"只读 core 默认开+危险工具注册/执行双闸"+agentgateway 清单级裁剪+openai-agents needs_approval 参数级动态判定，**default 方向必须显式**（三个 default-allow 陷阱实证）；Gateway=openai-agents 硬超时 error_as_result+autogen CancellationToken.link_future+HolmesGPT 双阈值 spill；Ledger=MCP TaskStatus/HolmesGPT APPROVAL_REQUIRED/langgraph interrupt≠error 三方支撑状态机+crewai 失败六分类+HolmesGPT HMAC 审批 token。
- **证据层（M4-19/20/10/11）**：契约=in-toto Statement 三段式（_type 版本 URI+subject digest map+predicateType）+OpenLineage 核心字段+facet 开放扩展+GUAC provenance 三元组 {collector, origin, documentRef}+SLSA external/internal 信任分级；digest 纪律=rekor 全链（**digest 对 canonical 字节算、存原始字节、读出原样返回、UUID=内容哈希、重复提交幂等**）；快照冻结=Iceberg"新 snapshot 不可变+parentId 链+CAS 提交"+Delta checkpoint+回放；篡改检测分级=L1 行 digest+聚合 CRC（Delta）、L2 可选 prev_digest 行链（immudb 最小移植）、L3 Merkle/签名不适用；append-only=eventuous PG SQL 骨架（FOR UPDATE expected-version+唯一约束显式报错+identity 全局序号）+Axon Java 同构互证。
- **裁决层（M4-21/22/23）**：Claim 契约=Keep 双哈希三分支（claim_fingerprint 判同一性/claim_hash 判内容等价→合并/覆盖/新建，ignore_fields 惯例，判定事件连 none 也落库）+deepeval strict_mode 二值口径（任一证据引用无效即整 claim 拒绝）+ragas claim 原子化逐条 verdict 带 reason；Reducer=表驱动不引规则引擎（easy-rules/rulebook 证明足够）+alertmanager 封闭枚举裁决出口（CONFIRMED/SUPPORTED/REFUTED/SUPERSEDED/NEEDS_REVIEW，无出口也显式记录）+drools TMS justification 表+级联撤销（普通 Java 实现）+dedupe"先分桶再桶内裁决"形态；Report Assembler=HolmesGPT 确定/推测分节形式（但分节依据必须来自裁决状态机而非 LLM 自述——HolmesGPT 无裁决层正是幻觉敞口的反证）+nflog append-only+快照回放。
- **预算层（M4-08/09/37）**：预留-实扣-平账三段式（litellm reservation+Helicone escrow 双先例，取消按 input floor 结算不退零，预留 ID 不复用请求 ID 防重放）；并发扣减=Bucket4j `SELECT FOR UPDATE` 行锁事务（Java 同栈直接先例，扣减 API 返 ConsumptionProbe 同构三元组）；五维组合=AutoGen 条件对象 OR 短路可序列化；终局保留=LangGraph PG checkpoint 按 thread_id 恢复+OpenHands ERROR 终态+Metrics.diff 子任务口径；usage 权威顺序=服务端 usage/cost 权威、本地估值仅事前封顶、**缺失记 UNMATCHED 不伪造零**（Langfuse/openai-agents 同语义）；耗尽路径零 LLM 调用（smolagents/CrewAI/LangChain 三家反例实证）；**默认 fail-closed**（litellm 默认 fail-open 为反面教训）。

## §5 跨册共性发现

1. **default-allow 陷阱多处复现**：agentgateway 空规则集全放行（rbac.rs:53-54，且有测试固化）、mcp-gateway 无配置条目默认放行（capabilitites.go:367-368）、kagent 空 tools 列表=全量（agenttemplates.yaml:369，schema 自述"harness 不能执行子集时退化为全量+告警"）、litellm 预算强制默认 fail-open（proxy_server.py:2426-2446）。教训统一：**空策略/存储不可用必须拒绝启动或显式确认，M4 全部默认 fail-closed**。
2. **LLM 审 LLM 反例链（跨预算层/裁决层/harness 三面）**：Goose Smart Approval 把读/写放行判给 LLM（判错即静默放行）；ragas/trulens/deepeval 的 claim 判定全靠 LLM/NLI 软判定；且三家评测库的"无证据默认"全部危险——trulens 弃权视为通过、deepeval 空=满分、ragas NaN 弃票。M4 对应硬语义：无证据引用=拒绝、说不清=NEEDS_REVIEW、空 claim 集=UNRESOLVED。
3. **耗尽后多调一次 LLM 的坑（三家同坑）**：smolagents 超限后 `_handle_max_steps_reached` 再调 model.generate（agents.py:606-607,846-848）；CrewAI docstring 自述 "Performs one more LLM call to get the final answer"（agent_utils.py:376-384）；LangChain `early_stopping_method="generate"` 超限后再做一次 forward pass（base.py:190-206）。M4-08 耗尽测试必须断言"耗尽路径零 LLM 调用"，三家可作测试对照证据。
4. **重名静默覆盖是普遍现状（三个反面证据）**：langgraph 注册循环 dict 直接赋值（tool_node.py:784）、SK-java CaseInsensitiveMap.put 无检测（KernelPlugin.java:47）、mcp-gateway 配置合并冲突只告警不拒绝（configuration.go:722-726）。M4-14 冲突检测 fail-fast 是差异化加固。
5. **"存对象、用时再序列化"必然漂移**：rekor 读出路径直接返回入库时持久化的 canonicalizedBody、不再重算（tle.go:99）——证据层必须存规范化原始字节，digest 验证走"重算 canonical 字节→比对"，不得走对象重序列化。
6. **异常/超时默认转模型可见结果（六方互证）**：MCP isError、spring-ai alwaysThrow=false、langchain handle_tool_error、langgraph status="error"、openai-agents error_as_result、crewai EXCEPTION 类——M4-17 采此默认，配合 HolmesGPT/OpenHands 的"审批/中断不落入 FAILED"语义。
7. **审批挂起态必须独立于 FAILED**：langgraph interrupt 走 GraphBubbleUp 永远上抛不转 error（tool_node.py:982-983）；HolmesGPT APPROVAL_REQUIRED 是一等结果状态（tools.py:64-69）；MCP TaskStatus 有 input_required 态（schema.ts:1306-1311）。
8. **快照冻结的必要性由反例印证**：GUAC 图可变合并（重复摄入 DoNothing 幂等合并，sbom.go:654）没有"旧结论不可变"语义——从反面印证 M4-20 迟到证据只产新快照、旧行不改的设计。
