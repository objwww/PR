## 任务 P1：Holmes 预算 feasibility spike（对应 AM3 M3-26，提前执行）

- **问题**：① HolmesGPT（195 上 `holmes` 容器，AM0 部署）调用模型时，能否在每次真实模型调用前硬拦预算（比如限制一次调查的最大 token/成本）？② Holmes 向模型端点发请求时能否透传自定义 metadata（如 run_id/attempt_id），使 LiteLLM spend log 可按此对账？
- **方法**：查 holmes 源码/配置文档（工具：本机 clone 或读 195 容器内文件）+ 设计最小实验（构造固定 prompt 多次调用，观察 token 消耗与拦截行为）
- **产出**：`docs/测试证据/AM3/spike-holmes-budget/`（实验脚本 + 原始输出 + 结论.md）
- **结论格式**：能硬拦 / 不能硬拦（标 BEST_EFFORT）+ 依据原文；能透传 / 不能透传 + 证据
