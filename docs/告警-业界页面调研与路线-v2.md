# 告警 Agent 业界页面调研与路线 v2（方案 v1 收官后的增量）

调研对象：Datadog（Bits AI/Watchdog）、PagerDuty（AIOps/Audit/Pages）、Rootly、incident.io、
Grafana OnCall、Moogsoft、Opsgenie、Backstage、LaunchDarkly、Argo Rollouts、Langfuse。

## 已收官（v1 全页面 + 增强）
总览/告警列表/详情(复核+断言+重查)/处置/值班/通知(静默)/评测(费用真值)/演练/监控/版本中心
(Diff+金丝雀建议)/交接摘要。对应业界：Bits AI 假设链、Rootly Handover、LaunchDarkly Diff、
Argo analysis、Langfuse 定价、PagerDuty 静默。

## 增量路线（按价值/可行度排序）
1. **审计与变更历史页**（业界：PagerDuty Audit Logs、LaunchDarkly 审计流、GitOps 审计）
   真源已有：认证事件（SecurityConfig recordAuthEvent）、配置变更事件、命令审计、
   rca_event 账本。纯只读聚合页：登录/登出、激活/回滚、命令四件套、静默增停。
   SRE 纪律"变更四问"（谁/何时/改了什么/为什么）的落地页面。
2. **AI 对话式诊断会话**（业界：Bits AI "Ask AI"、PagerDuty AI Insights）
   告警详情内嵌会话：针对当前 incident 提问，答案引用断言/证据/事件流水；
   会话落库可回放。依赖模型网关（已具备）。
3. **告警关联视图**（业界：Moogsoft 关联、Datadog Watchdog 聚类）
   同服务同时间窗告警聚类为一张"关联图/组视图"，标注疑似同因。
4. **服务目录**（业界：Backstage Catalog）：服务→负责人/排班/runbook/近7日告警数聚合视图。
5. **复盘（Postmortem）**（业界：Rootly/incident.io）：事故闭环后生成复盘草稿（含时间线/断言/费用）。
6. **ITSM 联动**（业界：ServiceNow/Jira 出单）——需要外部系统配置，放最后。

每项交付纪律沿方案 v1 第九节：真数据铁律/业界参照留痕/自驱推进/逐页截图台账。
