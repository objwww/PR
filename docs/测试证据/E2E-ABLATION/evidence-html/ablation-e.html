② 消融对照：若没有对账闭环

无 Reconciler/ESCALATED 出边的系统里，超时只有两条路：① 猜 FAILED → 可能误杀一次实际生效的变更（靶已执行但响应丢失）；② 猜 SUCCESS → 未验证的副作用被当成功放锁。两者都把"不确定"伪装成"确定"。
本系统把第三条路做成结构唯一：UNKNOWN 只能 RECONCILING，无探针证据只能 ESCALATED，锁在裁决前永不释放（TTL 仅孤儿化为 ORPHANED，不让渡）。

对照实验（PE-E3 实测）：PLAN(dry_run=false) → DISPATCHED → 靶 4xx → TIMEOUT_UNKNOWN
  → UNKNOWN → RECONCILING → ESCALATED(REAL_EXECUTION_NO_PROBE) → 人工 FAILED_CONFIRMED
  → 放锁（locks_left=0）；事件链 seq52–57 与 op 行如上，全链在案可审计。
