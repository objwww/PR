消融A：Guardian 低危白名单 有组件无组件

对象：MutationGuardian（确定性三值裁决：SAFE 自动签发 / UNSAFE 自动拒绝 / UNCERTAIN 转人工）。
切换方式：APP_ALERT_MUTATION_GUARDIAN_LOW_RISK_TOOLS（chaos.resolve → 空）+ 容器重建；同一 R2 意图（chaos.resolve，res://demo/checkout/ablation-a-*），仅白名单不同。

① 白名单开启（含 chaos.resolve）→ SAFE 自动批准

container_whitelist=chaos.resolve
auto_decide_A1={"verdict":"SAFE","approval_state":"APPROVED",
  "reason":"LOW_RISK_ALLOWLIST + PARAMS_IN_BUDGET",
  "request_id":"98fcf2ba-43d6-460f-a620-98fb773a96f8"}
request=98fcf2ba…|APPROVED
decision=guardian:pb-prod-v1|GUARDIAN|approved
grant=ff260118-f798-448f-9ead-819c15d686be|ACTIVE
event_on=SAFE|LOW_RISK_ALLOWLIST + PARAMS_IN_BUDGET

R2 单批即达 quorum：机器审批者 guardian:pb-prod-v1 落 decisions 表（显式可见）， Grant 即刻 ACTIVE。

② 白名单移除（空清单）→ UNCERTAIN 转人工

container_whitelist=<empty>
auto_decide_A2={"verdict":"UNCERTAIN","approval_state":"PENDING_HUMAN",
  "reason":"TOOL_NOT_IN_LOW_RISK_ALLOWLIST: chaos.resolve"}
request_count_for_A2=0          ← 不铸审批请求、不代决策，人工 decide 面接管
event_off=UNCERTAIN|TOOL_NOT_IN_LOW_RISK_ALLOWLIST: chaos.resolve

"宁可转人工，绝不硬凑 SAFE"：白名单一旦收窄，同一工具立即失去自动放行资格。

③ 还原与结论

APP_ALERT_MUTATION_GUARDIAN_LOW_RISK_TOOLS=chaos.resolve   ← .env 已还原
container_whitelist_restored=chaos.resolve
health=200 after 7x3s
状态Guardian 裁决审批状态人工介入
有白名单SAFEAPPROVED（grant 签发）零
无白名单UNCERTAINPENDING_HUMAN（零请求零代签）必须

组件差异：Guardian 白名单 = 低危工具自动执行的唯一通道；移除后自动化收益归零、安全性不降（fail-closed 转人工）。
