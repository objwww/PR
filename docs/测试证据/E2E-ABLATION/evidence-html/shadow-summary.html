指标口径与用途

指标评测意义
requests / approved / denied / expired审批漏斗：每个 mutation 意图恰好一个请求，无旁路
grants / consumed_authorizations授权范围签发 vs 恰一次消费（single-use CAS）
avg_decision_secondsGuardian 自动裁决成本（毫秒级，可忽略）
suspensions_total / activedurable 挂起（不占 slot）面使用情况
human_wait_seconds_totalLimited Autonomy 的人工代价显式化——UNCERTAIN/ESCALATED 的等待时间全部入账
