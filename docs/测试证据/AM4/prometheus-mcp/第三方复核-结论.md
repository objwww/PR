## 对主会话记录的三点勘误/补强（均为复核实证）

1. **`结论.md`"默认不含 quit/reload 类"表述不成立，须按此理解**：默认值 `--mcp.tools=all` 实测暴露 **30 个工具**，其中含 `quit`/`reload`/`delete_series`/`snapshot`/`clean_tombstones`（`raw/tools_all.tools_list.json`）。且 **`quit`/`reload` 不是退出 MCP 进程，而是代理 Prometheus 自身管理端点 `/-/quit`、`/-/reload`**——实测 all 模式调用 quit：服务端日志出现 `triggering Prometheus shutdown`，prometheus-am0 返回 403 仅因其未开 `--web.enable-lifecycle`；若目标开了 lifecycle，LLM 一次误调用即关停生产实例。help 文本所称 `--dangerous.enable-tsdb-admin-tools` 只约束 TSDB admin 工具的"启用使用"，**不阻止其在 all 模式的 tools/list 中出现**。→ **AM4 落码必须 `--mcp.tools=core` 或逐个 allow-list（主会话命令记录的 22 工具组合即正确示范），禁用 all；这是本次复核最重要的落码输入。**
2. **证据完整性交叉验证通过；仅 `stdio-抽查.md` 一个文档文件不在目录**：tjhop 轮 `raw/` 30 件原始报文复核确认完整在位（`raw/p6_*.txt`），本复核据其交叉验证——`p6_tool_names.txt` 实测 22 工具 = core 11 + 11 个追加只读工具（无 quit/reload/TSDB admin，与记录一致）；`p6_q_26/28` 负向 SSE 报文（`unknown tool "quit"/"delete_series"`）与本复核 core 轮负例逐字一致，两轮互证成立。**诚实更正**：本复核初稿曾误判"raw 30 件缺失"（只列父目录、未查 raw 内部），该说法撤回。本复核另存官方镜像原始件 `raw/tools_core.tools_list.json`、`raw/tools_all.tools_list.json`。
3. **"`ghcr.io/prometheus/prometheus-mcp` 不存在"为假阴性**：该判定仅测了 `:latest` tag（manifest unknown）；`:main` tag 实存可用（本复核全程运行的即该镜像，digest/版本见上）。ghcr 发布路径应以 **prometheus org + `main` tag + pin digest** 为准（与主会话 `结论.md`/完成清单行采用的镜像一致）；tjhop 路径为同源个人命名空间，二进制版本较旧（build 2026-04-25）。

## AM4 落码输入（复核增补）

- 启动参数模板见 `第三方复核-命令记录.md` §2（含 read-only rootfs/cap-drop 等加固，可直接抄）；
- 陷阱：kingpin 布尔开关不吃 `=false`（用 `--no-xxx`）；`range_query` 签名为 `start_time/end_time/step`（全 string，step 形如 `"120s"`），传 `start/end` 或整型会吃 schema 校验错；宿主 `127.0.0.1:18080` 已被占用，AM4 分配端口前先 `ss -ltn` 探测；
- 内嵌 7 个 runbook（check-system-health / investigate-error-rates / optimize-high-cardinality / review-prometheus-rules 等）+ docs_search 内置文档，可直接用作调查引导资产（与主会话 结论.md 注记一致）；
- 会话治理：keepalive 30s、空闲 10m 超时（默认），长调查会话需心跳；MCP 与 `/metrics` 同监听 ：8080，暴露面仅限 127.0.0.1/容器网。

## 纪律与清理

3 个一次性容器（均带内存限额）用完即删，`docker ps -a | grep p6-prom` 零残留；`prometheus-am0` 等存量容器零重启零改动（复核后仍 Up 8 hours）；镜像保留（主会话既有产物，AM4 复用）。全程未使用模型密钥；本目录证据文件（主会话 md×3 + raw 30 件 + 本复核 md×3 + tools JSON×2，共 38 个）经 9 类密钥/凭据字面量模式扫描 **0 命中**（命令与输出见 `第三方复核-命令记录.md` §8）。
