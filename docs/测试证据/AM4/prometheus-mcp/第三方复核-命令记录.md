## 1. 启动参数确认（--help 摘要，全文见会话转录）

- `--mcp.tools=all`（默认）；`core` = 11 工具白名单；其余取值为"core 之外追加"的 allow-list；
- `--mcp.transport`：stdio（默认）/ http；
- `--dangerous.enable-tsdb-admin-tools`：snapshot/delete_series/clean_tombstones 的启用开关（默认关）；
- `--prometheus.url`、`--prometheus.timeout`、`--web.listen-address`、`--mcp.keepalive-interval=30s`、`--mcp.session-timeout=10m`。
- **踩坑①**：kingpin 布尔开关不接受 `=false`——`--docs.auto-update=false` 启动即报 `error: unexpected false` 退出 rc=1；用 `--no-xxx` 或省略（该开关默认即关）。

## 2. 启动（内存限额 + 加固，用完即删）

```bash
# 踩坑②：宿主 127.0.0.1:18080 已被占用（Bind failed），换 18123（不碰占用者）
$ docker run -d --rm --name p6-prommcp \
    --memory=256m --memory-swap=256m --cpus=1 \
    --read-only --tmpfs /tmp:rw,noexec,nosuid,size=16m \
    --cap-drop=ALL --security-opt=no-new-privileges \
    --network alert-net \
    -p 127.0.0.1:18123:8080 \
    ghcr.io/prometheus/prometheus-mcp:main \
    --mcp.transport=http --mcp.tools=core \
    --prometheus.url=http://prometheus-am0:9090 \
    --prometheus.timeout=30s \
    --web.listen-address=:8080 --log.level=info
# 启动日志：toolset=core → "MCP server created" tool_count=11 → Listening on [::]:8080
```

inspect 实证：`mem=268435456 memswap=268435456 nanocpus=1000000000 readonly_rootfs=true user=nobody cap_drop=[ALL] security_opt=[no-new-privileges] ports={8080/tcp:[{127.0.0.1 18123}]}`

## 3. MCP 会话（streamable http）

端点 `POST /mcp`；Accept 须含 `application/json, text/event-stream`；响应 SSE 帧；会话头 `Mcp-Session-Id`；`notifications/initialized` → 202。每轮验证新建会话（共 6 次 initialize，均成功）。辅助探测：`GET /` 与 `GET /metrics` 均 200——**MCP 与自指标同监听 ：8080，端口只可绑 127.0.0.1 或不出容器网络**。
