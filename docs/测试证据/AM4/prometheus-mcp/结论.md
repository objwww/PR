## 注意

- ghcr 标签只有 `main`（无 latest/版本 tag）——生产使用时应 pin digest。
- server 内嵌 runbook 体系（check-system-health / investigate-error-rates / optimize-high-cardinality 等 7 个）——AM4 可直接用作调查引导资产。
- 与 Holmes 自带 prometheus toolset 的关系：AM4 前基线仍是 Holmes 自带（架构 v2.1 §12）；本组件是 Native 内核工具层的候选。
