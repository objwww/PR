## 1. AM4 生产装配清单（docker profile，手工装配）

| Bean | 组件 / 任务 | 说明 |
|---|---|---|
| `am4ToolRegistry` | ToolRegistry | prometheus.query=真实 `PrometheusQueryExecutor`；logs.query / change.query=冻结 fixture `ReplayToolExecutor`（P0-7：无实时源，fixture 即数据面） |

| `am4ReplayRunner` | AgentReplayRunner（M4-33） | E2E-M4-08 回放链工具出口；覆盖率/Token 申报 |
| `am4ShadowPool` | ExecutorService | 影子独立并发槽（容器关停 shutdown） |
| `am4ShadowToolFace` | ShadowToolFace（M4-35） | 仅 R0/R1 + REDTEAM 双闸 + 独立限流；`readOnlyView()` 供 Agent 校验面同源 |
| `am4ShadowRouter` | SnapshotShadowRouter（M4-34） | 同 digest 盖章 / 独立预算 / 失败隔离 / 无发布出口 |
| `am4AgentRegistry` | AgentRegistry（M4-24） | metrics/logs/change 三固定 Agent，启动期 fail-fast |
| `am4MetricsAgent` 等 | 三 Agent | 工具出口只绑影子面（Holmes 主链零改动） |
| `am4NativeRcaAgent` | NativeRcaAgent（M4-30） | 黑板 → Claim，不发布 |
| `am4ClaimReducer` | ClaimReducer（M4-22） | 降级续跑白名单配置化 |
| `am4DeterministicSupervisor` | Supervisor（M4-25/26） | PlanCompiler + DagExecutionService（复用 AlertFlowConfig bean）+ 恢复入口 advance |

依赖的既有 bean（`PersistenceConfig`）：`JdbcClient`、`TransactionOperations`、
`rcaTaskRepository`、`taskEdgeRepository`、`rcaRunRepository`、`evidenceRepository`、
`rcaToolInvocationLedger`、`claimStore`。
