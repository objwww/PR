## 4. 与我们 compose hardening 的关联清单（核心交付）

**4.1 已达标项（本轮 PASS/未列入 WARN 的证据）**
- 5.4 cap 限制 / 5.5 无 privileged 容器：全栈 PASS。
- 5.14 端口绑定特定宿主接口：PASS（佐证 127.0.0.1 绑定纪律，公网零暴露未破）。
- 5.11 内存限额：control-app(768M)/postgres(512M)/prometheus(300m)/holmesgpt(1536m)/order-arena(512m)/arena-chaos-admin(384m) 均在位，未列入 5.11 WARN。
- 5.13 rootfs 只读：control-app/order-arena/arena-chaos-admin 未列入 5.13 WARN。
- 5.26 no-new-privileges：上述四容器未列入 WARN。
- 5.27 健康检查：postgres/order-arena/arena-chaos-admin 未列入 WARN。
- 4.1 非 root：control-app 镜像（uid 10001）未列入 WARN。
- 5.22 postgres `seccomp:unconfined` 被点名为唯一 seccomp 禁用项 = **INC-09 已知例外**（kernel 3.10），维持现状。

**4.2 我们 compose 的整改候选（按影响排序，仅供主会话裁定，本任务未改）**
1. **pids_limit 全缺（5.29）**：27/27 容器全中，是覆盖面最大的单点；compose 逐服务补 `pids_limit`（如业务 100/基础设施 200）即可翻转。
2. **alertmanager-am0 无 mem_limit（5.11）**：alert 栈唯一漏项；echo-receiver 同缺但系 AM0 遗留散置容器、不在当前 compose 内。
3. **健康检查缺（5.27）**：deploy-control-app-1、alertmanager-am0、holmesgpt-am1、prometheus-am0 四服务。
4. **CPU 限额缺（5.12）**：alert 栈全部 5 服务（主栈 postgres/control-app 已有 cpus=1.0 范例可套）。
5. **read_only 未开（5.13）**：prometheus/alertmanager/holmesgpt/postgres（需评估各自数据落盘路径后加 tmpfs/volume）。
6. **no-new-privileges 缺（5.26）**：prometheus/alertmanager/postgres/echo-receiver。
7. **镜像 USER 缺（4.1）**：holmesgpt-am1（local/holmesgpt）以 root 运行，是 4.1 WARN 中唯一我们自建镜像。
8. 环境性项（5.2/5.3）：CentOS7+kernel3.10 下 SELinux 难启用，建议在安全门文档标注为"环境限制接受"，不进整改队列。

**4.3 非本仓库范围、建议上报主会话的发现**
- **otel-collector 挂载宿主 `/`（5.6，读写敏感目录）与 docker.sock（5.32）**：otel demo 栈既有形态，是本轮最高风险两杀；处置归属 demo 栈负责人。
- **`infallible_saha` 容器**（local/holmesgpt:am1-http）：默认 docker0 网桥（5.30 INFO 点名）、无内存/CPU/PIDs 限额、root 运行；非本任务产物（疑似并行 P1 spike 遗留），按纪律未动，请主会话处置。
- 镜像 sprawl：87 个镜像仅 29 个在用（6.1）；容器 29 个/28 运行（6.2）。
- 宿主层：auditd docker 审计规则全缺（1.1.x）、daemon.json 七项加固未做（§2 WARN）——安全门后续运维 backlog。

## 7. 结论摘要（约 200 字）

195 上完成 CIS Docker Benchmark 基线：Hub 镜像过期（v1.3.4），按预案以官方 master v1.6.0 源码构建后一次性容器跑分（--rm+512M 内存限额，挂载全只读，30 秒全量 117 检查，未改任何配置）。结果 PASS 36 / WARN 29 / INFO 43 / NOTE 9。29 项 WARN 中与本仓库 compose hardening 直接相关的整改候选为：全体容器缺 pids_limit（覆盖面最大）、alertmanager 缺内存限额、control-app/alertmanager/holmesgpt/prometheus 缺健康检查、alert 栈全缺 CPU 限额、prometheus/alertmanager/holmesgpt/postgres 未开 read_only、同四者缺 no-new-privileges、holmesgpt 镜像以 root 运行；postgres seccomp:unconfined 属 INC-09 已知例外。127.0.0.1 绑定、cap_drop、无 privileged 等既有纪律全部实测达标。另发现 otel-collector 挂载宿主 / 与 docker.sock、疑似 P1 遗留容器 infallible_saha 在默认网桥无限额，均已上报待主会话处置。容器清单前后一致，服务器零残留。
