## 1. 背景简报（M3 是什么 / 栈现状 / 首跑警告）

**M3 四大能力**（详见 `docs/M3-技术方案.md` v1.5 §4，执行不必通读，矩阵条目自带回指）：

1. **ModelGateway 唯一出口**：`ReviewAgentLoop` 只依赖上层端口 `ModelGatewayPort`；
   底层 `RouteClientPort` 每路由一个实例（Spring AI 手工双装配）；M0 的
   `ModelClient`/`ModelBudgetGuard` 已删除退役。一次 `RouteClientPort.complete()` 最多
   一次真实 HTTP——Spring AI 隐藏重试已关（`spring.ai.retry.max-attempts=1`，I34/INC-42）。
2. **`model_call_ledger` 两段记账（V5 迁移，裁定 C-3）**：触网前 `insertStarted`
   （STARTED 行写失败 = 零触网 fail-closed）；终态条件更新（SUCCEEDED/FAILED）；
   崩溃遗留 STARTED 由 `ModelCallLedgerRecovery` 超龄标 UNKNOWN（默认 240s 阈值 +
   60s 扫描周期，启动时必扫一次）。成本快照（pricing_version + 单价）随终态落账。
3. **路由 / 熔断 / 预算 / 总 deadline**：主备双路由 + 故障域矩阵（quota scope 同域
   账号级故障不切备，I36）；三态熔断器 + HALF_OPEN 恰好一发探针（BreakerPermit）；
   四类预算（max-physical-calls-per-step 等，附录 B 公式）+ Gateway 总 deadline
   （默认 300s）+ inline-retry-max-delay（默认 15s，超出走 Defer 挂
   `work_item.available_at`，不占死 Worker）。
4. **checkpoint 模型身份（I30，§4.7）**：checkpoint 落**实际路由**契约身份
   （`provider/requestedModel/contract-version` 三段 canonical，如
   `openai-compatible/qwen-plus/configured`）；恢复时按保存路由重算契约 digest；
   fallback 的 checkpoint 在主路由恢复后仍复用（v1.1 废止"回主即丢弃"）。
